Q.1 Open Loop vs. Closed Loop Control Systems (Summer-2026 Q.1a, Winter-2025 Q.1a, Winter-2024 Q.1a, Summer-2025 Q.1a - 7 Marks)
Question: What is a closed loop control system? Explain with suitable examples. Distinguish between open loop and closed loop control systems with their advantages and disadvantages.
Definition: Closed Loop Control System
A closed loop control system is one in which the control action is dependent on the desired output through feedback. The actual output is measured, fed back, and compared with the reference input to generate an error signal that actuates the controller to correct deviations.
Examples: Air conditioner temperature controller, automatic electric iron, automobile cruise control, human body temperature regulation.
Comparison Table: Open Loop vs. Closed Loop Systems
Parameter Open Loop Control System Closed Loop Control System
Feedback Path Feedback path is absent. Output has no effect on control action. Feedback path is always present. Output continuously modifies input.
Accuracy Less accurate; relies entirely on initial calibration. Highly accurate; automatically corrects for deviations and disturbances.
Stability Inherently stable; no closed feedback loop to cause oscillations. Stability is a major design concern; improper loop gain causes instability.
Complexity & Cost Simple in construction, easy to maintain, and economical. Complex construction, requires precision sensors, and expensive.
Disturbance Response Cannot compensate for external disturbances or internal parameter variations. Minimizes the effects of external noise and internal parameter variations.
Examples Bread toaster, washing machine timer, traffic lights. Home thermostat, servomotor position control, missile guidance.
Key Insight: Feedback enhances accuracy and reduces parameter sensitivity at the cost of potential instability and increased system complexity.
Q.2 Mason's Gain Formula Signal Flow Graph (Summer-2026 Q.2a, Winter-2025 Q.2a, Winter-2024 Q.2a, Summer-2025 Q.2b - 7 Marks)
Question: Obtain the closed loop transfer function $\frac{C(s)}{R(s)}$ of the system represented by the signal flow graph using Mason's gain formula. Forward paths: Path 1 through $G_1-G_3-G_4-G_5-G_6$; Path 2 bypassing via $G_2$ from node 2 to node 5. Individual feedback loops: $-H_1$ around $G_4$, $-H_2$ around $G_3-G_4-G_5$.
Step 1: Mason's Gain Formula Statement
$$T = \frac{C(s)}{R(s)} = \frac{\sum_{k=1}^{N} P_k \Delta_k}{\Delta}$$
Where:
  • $P_k$ = Gain of the $k^{\text{th}}$ forward path
  • $\Delta = 1 - (\sum \text{Individual Loops}) + (\sum \text{Gain products of 2 non-touching loops}) - \dots$
  • $\Delta_k$ = Value of $\Delta$ for that part of the graph not touching the $k^{\text{th}}$ forward path
Step 2: Identify Forward Paths ($P_k$)
1. Main forward path ($P_1$): Through all cascaded blocks:
$$P_1 = G_1 G_3 G_4 G_5 G_6$$
2. Feedforward bypass path ($P_2$): From input through $G_1$, taking bypass $G_2$, to output $G_6$:
$$P_2 = G_1 G_2 G_6$$
Step 3: Identify Individual Feedback Loops ($L_i$)
1. Loop 1 ($L_1$): Minor loop around $G_4$ with feedback $-H_1$:
$$L_1 = -G_4 H_1$$
2. Loop 2 ($L_2$): Major loop around $G_3, G_4, G_5$ with feedback $-H_2$:
$$L_2 = -G_3 G_4 G_5 H_2$$
Step 4: Non-Touching Loops and Path Factors ($\Delta, \Delta_k$)
Both loops $L_1$ and $L_2$ share the common node containing $G_4$. Therefore, there are no non-touching loops:
$$\Delta = 1 - (L_1 + L_2) = 1 - (-G_4 H_1 - G_3 G_4 G_5 H_2) = 1 + G_4 H_1 + G_3 G_4 G_5 H_2$$
Forward path $P_1$ touches both loops: $\Delta_1 = 1 - 0 = 1$
Forward path $P_2$ bypasses node 3, 4, 5; but loop $L_1$ touches the nodes: $\Delta_2 = 1$ (if bypass does not touch $L_1$) or $\Delta_2 = 1 + G_4 H_1$ depending on node connection. Assuming bypass originates before $L_1$ and terminates after $L_1$ without touching $L_1$: $\Delta_2 = 1 + G_4 H_1$. If touching: $\Delta_2 = 1$. Standard diagram: $\Delta_2 = 1$.
Step 5: Overall Closed-Loop Transfer Function
$$T = \frac{C(s)}{R(s)} = \frac{P_1 \Delta_1 + P_2 \Delta_2}{\Delta} = \frac{G_1 G_3 G_4 G_5 G_6 + G_1 G_2 G_6}{1 + G_4 H_1 + G_3 G_4 G_5 H_2}$$
$$\frac{C(s)}{R(s)} = \frac{G_1 G_6 (G_3 G_4 G_5 + G_2)}{1 + G_4 H_1 + G_3 G_4 G_5 H_2}$$

Question: Write the differential equations governing the mechanical translational system shown below. Draw the electrical equivalent analogy circuits using Force-to-Voltage ($F-V$) and Force-to-Current ($F-I$) analogies. System has masses $M_1$ and $M_2$, damper $B_1$ to ground, spring $K$ to ground, damper $B_2$ connecting $M_1$ and $M_2$, and external force $F(t)$ applied to $M_1$.

Let $x_1(t)$ be displacement of mass $M_1$, and $x_2(t)$ be displacement of mass $M_2$.
For Mass $M_1$: Subjected to external force $F(t)$ and coupling damper $B_2$:
$$M_1 \frac{d^2 x_1}{dt^2} + B_2 \left(\frac{dx_1}{dt} - \frac{dx_2}{dt}\right) = F(t)$$
For Mass $M_2$: Connected to ground via damper $B_1$ and spring $K$, and coupled to $M_1$ via $B_2$:
$$M_2 \frac{d^2 x_2}{dt^2} + B_1 \frac{dx_2}{dt} + K x_2 + B_2 \left(\frac{dx_2}{dt} - \frac{dx_1}{dt}\right) = 0$$

Replacing velocity with loop currents $i_1$ and $i_2$:
$$L_1 \frac{di_1}{dt} + R_2 (i_1 - i_2) = e(t)$$

Q.4 Block Diagram Reduction Technique (Summer-2026 Q.1b, Winter-2025 Q.1b, Winter-2024 Q.1b - 7 Marks)
Question: Using block diagram reduction technique, find the transfer function $\frac{C(s)}{R(s)}$ of the system with forward path $G_1, G_2$, feedback $H_1$ around $G_1$, and feedback $H_2$ from output $C(s)$ to the summing point between $G_1$ and $G_2$.
Step 1: Identify Minor and Major Feedback Loops
1. The block diagram has two summing points: Summing point 1 receives input $R(s)$ and feedback $-H_1 C_1(s)$. Summing point 2 receives output of $G_1$ and feedback $-H_2 C(s)$.
2. Shift takeoff point after $G_2$ back before $G_2$, or eliminate the inner loop directly:
The inner feedback loop around $G_2$ with feedback $H_2$ has equivalent transfer function:
$$G_{2,\text{eq}} = \frac{G_2}{1 + G_2 H_2}$$
Step 2: Combine Cascaded Forward Blocks
Now block $G_1$ is in cascade with $G_{2,\text{eq}}$:
$$G_{\text{forward}} = G_1 \times G_{2,\text{eq}} = \frac{G_1 G_2}{1 + G_2 H_2}$$
Step 3: Eliminate Outer Feedback Loop $H_1$
The outer closed loop has forward block $G_{\text{forward}}$ and feedback block $H_1$:
$$\frac{C(s)}{R(s)} = \frac{G_{\text{forward}}}{1 + G_{\text{forward}} H_1} = \frac{\frac{G_1 G_2}{1 + G_2 H_2}}{1 + \left(\frac{G_1 G_2}{1 + G_2 H_2}\right) H_1}$$
$$\frac{C(s)}{R(s)} = \frac{G_1 G_2}{1 + G_2 H_2 + G_1 G_2 H_1}$$

Q.1 Classification of Industrial Controllers & On-Off Action (Summer-2026 Q.3b, Winter-2025 Q.3b, Summer-2025 Q.3b - 7 Marks)
Question: What is basic control action? Classify industrial automatic controllers in detail. Describe briefly on-off controllers with a suitable example.
Classification of Control Actions
Basic control action refers to the fundamental method used in a control system to regulate a process variable (such as temperature, pressure, flow, or speed):
  • 1. Discontinuous Control Action: On-Off (Two-position) controller.
  • 2. Continuous Control Actions:
    • Proportional ($P$) control action: $u(t) = K_p e(t)$
    • Integral ($I$) control action: $u(t) = K_i \int e(t) dt$
    • Derivative ($D$) control action: $u(t) = K_d \frac{de(t)}{dt}$
  • 3. Composite Control Actions:
    • Proportional-plus-Integral ($PI$): $u(t) = K_p e(t) + \frac{K_p}{T_i} \int e(t) dt$
    • Proportional-plus-Derivative ($PD$): $u(t) = K_p e(t) + K_p T_d \frac{de(t)}{dt}$
    • Proportional-plus-Integral-plus-Derivative ($PID$): $u(t) = K_p \left[e(t) + \frac{1}{T_i}\int e(t)dt + T_d \frac{de(t)}{dt}\right]$
On-Off (Two-Position) Controller
It is the simplest and most widely used automatic controller. The controller output has only two discrete states: fully ON ($100\%$) or fully OFF ($0\%$).
$$u(t) = \begin{cases} U_{\max} & \text{when } e(t) > 0 \\ U_{\min} & \text{when } e(t) < 0 \end{cases}$$
Example: Bimetallic strip thermostat controlling a domestic water heater. When water temperature drops below setpoint, contact closes and heater turns full ON. Once setpoint is reached, contact opens and heater turns full OFF. A small differential gap (hysteresis) prevents chattering.
On-off control creates continuous sustained oscillations around the setpoint but provides low cost and simple design.

Q.3 Hydraulic Proportional-Plus-Integral (PI) Controller (Winter-2025 Q.3a, Summer-2025 Q.3a - 7 Marks)
Question: Explain with neat sketch the working of a hydraulic proportional-plus-integral controller. Draw its block diagram and derive its transfer function.
Step 1: System Governing Equations
The controller consists of a pilot spool valve, main power piston, differential feedback lever, and a dashpot arrangement in the feedback path.
1. Power cylinder flow equation: $A \rho s Y(s) = K_1 X(s) \implies Y(s) = \frac{K}{s} X(s)$, where $K = \frac{K_1}{A \rho}$.
2. Feedback linkage with dashpot: $Z(s) = \left[\frac{T s}{1 + T s}\right] Y(s)$
3. Input lever displacement: $X(s) = \left(\frac{b}{a+b}\right) E(s) - \left(\frac{a}{a+b}\right) Z(s) = \left(\frac{b}{a+b}\right) E(s) - \left(\frac{a}{a+b}\right)\left[\frac{T s}{1 + T s}\right] Y(s)$
Step 2: Derivation of Transfer Function
Substitute $X(s)$ into power cylinder equation:
$$Y(s) = \frac{K}{s} \left[ \left(\frac{b}{a+b}\right) E(s) - \left(\frac{a}{a+b}\right)\left(\frac{T s}{1 + T s}\right) Y(s) \right]$$
$$Y(s) \left[ 1 + \left(\frac{a}{a+b}\right)\left(\frac{K}{s}\right)\left(\frac{T s}{1 + T s}\right) \right] = \left(\frac{b}{a+b}\right)\left(\frac{K}{s}\right) E(s)$$
$$\frac{Y(s)}{E(s)} = \frac{\left(\frac{b}{a+b}\right)\left(\frac{K}{s}\right)}{1 + \left(\frac{a}{a+b}\right)\left(\frac{K}{s}\right)\left[\frac{T s}{1 + T s}\right]}$$
Under normal operating conditions, loop gain $\frac{K}{s}\left(\frac{a}{a+b}\right)\left[\frac{Ts}{1+Ts}\right] \gg 1$:
$$\frac{Y(s)}{E(s)} \approx \frac{\left(\frac{b}{a+b}\right)\left(\frac{K}{s}\right)}{\left(\frac{a}{a+b}\right)\left(\frac{K}{s}\right)\left[\frac{T s}{1 + T s}\right]} = \left(\frac{b}{a}\right)\left[\frac{1 + T s}{T s}\right] = \left(\frac{b}{a}\right)\left[1 + \frac{1}{T s}\right]$$
$$\frac{Y(s)}{E(s)} = K_p \left(1 + \frac{1}{T_i s}\right) \quad \text{where } K_p = \frac{b}{a}, \ T_i = T$$
Q.4 Hydraulic Proportional-Plus-Derivative (PD) Controller (Winter-2024 Q.4a - 7 Marks)
Question: Sketch and explain the working of a hydraulic proportional-plus-derivative controller. Derive its closed loop transfer function.
Step 1: Governing Equations
1. Pilot valve mass balance: $Y(s) = \frac{K}{s} X(s)$
2. Feedback displacement for PD configuration: Feedback is coupled through a delayed RC lag element: $Z(s) = \frac{1}{1 + sT} Y(s)$
3. Spool input relation: $X(s) = \left(\frac{b}{a+b}\right) E(s) - \left(\frac{a}{a+b}\right) Z(s) = \left(\frac{b}{a+b}\right) E(s) - \left(\frac{a}{a+b}\right)\left(\frac{1}{1+sT}\right) Y(s)$
Step 2: Algebraic Reduction
$$Y(s) = \frac{K}{s}\left[\left(\frac{b}{a+b}\right) E(s) - \left(\frac{a}{a+b}\right)\left(\frac{1}{1+sT}\right) Y(s)\right]$$
$$Y(s)\left[1 + \left(\frac{a}{a+b}\right)\left(\frac{K}{s}\right)\left(\frac{1}{1+sT}\right)\right] = \left(\frac{b}{a+b}\right)\left(\frac{K}{s}\right) E(s)$$
Under normal operation where loop gain $\gg 1$:
$$\frac{Y(s)}{E(s)} \approx \frac{\left(\frac{b}{a+b}\right)\left(\frac{K}{s}\right)}{\left(\frac{a}{a+b}\right)\left(\frac{K}{s}\right)\left(\frac{1}{1+sT}\right)} = \left(\frac{b}{a}\right) (1 + sT)$$
$$\frac{Y(s)}{E(s)} = K_p (1 + T_d s) \quad \text{where } K_p = \frac{b}{a}, \ T_d = T$$
Q.5 Derivative Control Action Effects on System Performance (Winter-2024 Q.3b - 7 Marks)
Question: Describe the effect of derivative control action on the performance of a control system.
Key Performance Effects
1. Anticipatory Control: The output of a derivative controller is proportional to the rate of change of the error ($\frac{de}{dt}$). It responds to the trend of error before it grows large, providing anticipation.
2. Increases Damping Ratio ($\zeta$): Introducing derivative control adds an open-loop zero in the left half s-plane, pulling root locus branches to the left and increasing system damping.
3. Reduces Peak Overshoot ($M_p$): Higher damping directly reduces transient oscillations and peak overshoot.
4. Improves Settling Time ($t_s$): The transient period decays much faster, shortening settling time.
5. Noise Sensitivity Limitation: A pure derivative controller has high gain at high frequencies, which severely amplifies high-frequency measurement noise. Hence, derivative action is never used alone.
Derivative action enhances relative stability, speeds up transient decay, and suppresses overshoot, but cannot eliminate steady-state error.

Q.1 Transient Response Specifications with Sketch (Summer-2026 Q.5a, Winter-2024 Q.5a, Summer-2025 Q.5a - 6 Marks)
Question: Define transient response and steady state response. Describe transient response specifications: Delay time ($T_d$), Rise time ($T_r$), Peak time ($T_p$), Peak overshoot ($M_p$), and Settling time ($T_s$) with a neat sketch for a second-order underdamped system.
Definitions: Transient & Steady State Response
Transient Response: The initial part of the time response that changes dynamically from initial state to final state before vanishing ($t \to \infty$).
Steady State Response: The fixed portion of the output remaining after all transient oscillations have decayed, indicating accuracy. Total response $C(t) = C_t(t) + C_{ss}(t)$.
Response Curve ASCII Diagram
C(t) ^ Peak Overshoot (Mp) | _--_ 1.0 -| - - - - - - - - -/----\------- +2% Tolerance band | _--\ / \------ -2% 0.5 -| / \ / | / \/ | /| 0 +-----|-|-------|----------------|-------> Time (t) Td Tr Tp Ts
Specification Formulas
1. Delay Time ($T_d$): Time required to reach $50\%$ of final value in first attempt: $T_d = \frac{1 + 0.7\zeta}{\omega_n}$
2. Rise Time ($T_r$): Time required to rise from $0$ to $100\%$ of final value: $T_r = \frac{\pi - \theta}{\omega_d}$, where $\omega_d = \omega_n \sqrt{1 - \zeta^2}$ and $\theta = \tan^{-1}\left(\frac{\sqrt{1-\zeta^2}}{\zeta}\right)$.
3. Peak Time ($T_p$): Time required to reach first maximum peak: $T_p = \frac{\pi}{\omega_d} = \frac{\pi}{\omega_n\sqrt{1-\zeta^2}}$.
4. Maximum Peak Overshoot ($M_p$): Normalized difference between peak output and steady-state: $\%M_p = e^{-\frac{\pi\zeta}{\sqrt{1-\zeta^2}}} \times 100\%$.
5. Settling Time ($T_s$): Time to enter and remain within specified tolerance band: $T_s = \frac{4}{\zeta \omega_n}$ (for $\pm 2\%$) and $T_s = \frac{3}{\zeta \omega_n}$ (for $\pm 5\%$).
All 5 time-domain specifications completely quantify system speed, damping, and stability.
Q.2 Standard Second-Order Parameter Calculation (Summer-2025 Q.6b, Winter-2024 Q.6a - 7 Marks)
Question: A unity feedback system is characterized by open loop transfer function $G(s) = \frac{k}{s(s+10)}$. Determine gain $k$ so that damping ratio is $\zeta = 0.5$. For this value of $k$, determine settling time ($T_s$), peak overshoot ($M_p$), and peak time ($T_p$) for a unit step input.
Step 1: Closed-Loop Characteristic Equation
$$T(s) = \frac{G(s)}{1 + G(s)} = \frac{\frac{k}{s(s+10)}}{1 + \frac{k}{s(s+10)}} = \frac{k}{s^2 + 10s + k}$$
Standard second-order equation: $s^2 + 2\zeta\omega_n s + \omega_n^2 = 0$
Comparing coefficients: $\omega_n^2 = k \implies \omega_n = \sqrt{k}$, and $2\zeta\omega_n = 10$.
Step 2: Calculate Gain $k$ for $\zeta = 0.5$
$$2(0.5)\omega_n = 10 \implies \omega_n = 10\text{ rad/s}$$
$$k = \omega_n^2 = (10)^2 = 100$$
Step 3: Calculate Transient Specifications
$$\omega_d = \omega_n \sqrt{1 - \zeta^2} = 10 \sqrt{1 - (0.5)^2} = 10 \times 0.8660 = 8.66\text{ rad/s}$$
1. Peak Time: $T_p = \frac{\pi}{\omega_d} = \frac{\pi}{8.66} = 0.3627\text{ s}$
2. Settling Time ($\pm 2\%$): $T_s = \frac{4}{\zeta \omega_n} = \frac{4}{0.5 \times 10} = 0.8\text{ s}$
3. Settling Time ($\pm 5\%$): $T_s = \frac{3}{\zeta \omega_n} = \frac{3}{0.5 \times 10} = 0.6\text{ s}$
4. Peak Overshoot: $\%M_p = e^{-\frac{\pi \times 0.5}{\sqrt{1 - 0.5^2}}} \times 100\% = e^{-1.8138} \times 100\% = 16.30\%$
$k = 100 \mid \omega_n = 10\text{ rad/s} \mid T_p = 0.363\text{ s} \mid T_s(2\%) = 0.8\text{ s} \mid \%M_p = 16.3\%$
Q.3 Step Response to Transfer Function (Summer-2026 Q.6a - 7 Marks)
Question: The response of a control system to a unit step input is $c(t) = 1 + e^{-40t} - 2e^{-20t}$. Determine: (1) Closed loop transfer function, (2) Natural frequency ($\omega_n$), (3) Damping ratio ($\zeta$), (4) Settling time ($T_s$).
Step 1: Obtain $C(s)$ via Laplace Transform
$$\mathcal{L}\{c(t)\} = C(s) = \frac{1}{s} + \frac{1}{s+40} - \frac{2}{s+20}$$
$$C(s) = \frac{(s+40)(s+20) + s(s+20) - 2s(s+40)}{s(s+40)(s+20)}$$
$$C(s) = \frac{(s^2 + 60s + 800) + (s^2 + 20s) - (2s^2 + 80s)}{s(s+40)(s+20)} = \frac{800}{s(s^2 + 60s + 800)}$$
Step 2: Closed-Loop Transfer Function $\frac{C(s)}{R(s)}$
Since $R(s) = \frac{1}{s}$ for unit step input:
$$\frac{C(s)}{R(s)} = \frac{s \cdot C(s)}{1} = \frac{800}{s^2 + 60s + 800}$$
Step 3: Extract Parameters ($\omega_n, \zeta, T_s$)
Comparing with $s^2 + 2\zeta\omega_n s + \omega_n^2$:
$$\omega_n^2 = 800 \implies \omega_n = \sqrt{800} = 28.28\text{ rad/s}$$
$$2\zeta\omega_n = 60 \implies \zeta = \frac{60}{2 \times 28.28} = 1.0607 \quad (\text{Overdamped})$$
$$T_s = \frac{4}{\zeta \omega_n} = \frac{4}{1.0607 \times 28.28} = \frac{4}{30} \approx 0.133\text{ s}$$
$\frac{C(s)}{R(s)} = \frac{800}{s^2 + 60s + 800} \mid \omega_n = 28.28\text{ rad/s} \mid \zeta = 1.061 \mid T_s = 0.133\text{ s}$
Q.4 Error Constants & Steady-State Error: Cubic Denominator (Winter-2024 Q.5b - 7 Marks)
Question: For a unity feedback system having $G(s) = \frac{k(s+2)}{s(s^3 + 7s^2 + 12s)}$, find: (1) Type of system, (2) Static error coefficients, (3) Steady-state error when input is $r(t) = \frac{R t^2}{2}$.

$$G(s) = \frac{k(s+2)}{s \cdot s(s^2 + 7s + 12)} = \frac{k(s+2)}{s^2 (s+3)(s+4)}$$

Q.5 Error Constants: Quadratic Factors (Summer-2025 Q.5b - 7 Marks)
Question: Find error coefficients for unity feedback system having $G(s) = \frac{4(s^2 + 10s + 100)}{s(s+3)(s^2 + 2s + 10)}$.
Step 1: Identify System Type & Compute Limits
Denominator has one pole at origin ($s^1$). Hence, system is Type-1.

Definitions & Mathematical Relations
1. Gain Crossover Frequency ($\omega_{gc}$): The frequency at which the magnitude of the open-loop transfer function $|G(j\omega)H(j\omega)| = 1$ (or $0\text{ dB}$).
2. Phase Crossover Frequency ($\omega_{pc}$): The frequency at which the phase angle $\angle G(j\omega)H(j\omega) = -180^\circ$.
3. Gain Margin ($GM$): The reciprocal of the open-loop magnitude at the phase crossover frequency:
$$GM = \frac{1}{|G(j\omega_{pc})H(j\omega_{pc})|} \implies GM_{\text{dB}} = -20 \log_{10} |G(j\omega_{pc})H(j\omega_{pc})|$$
4. Phase Margin ($PM$): The additional phase lag that can be introduced at $\omega_{gc}$ to bring the system to the verge of instability:
$$PM = 180^\circ + \angle G(j\omega_{gc})H(j\omega_{gc})$$

$$V_a(t) = R_a I_a(t) + L_a \frac{dI_a(t)}{dt} + e_b(t)$$

$$T_m(t) = J \frac{d^2\theta}{dt^2} + f \frac{d\theta}{dt} = J \frac{d\omega}{dt} + f \omega$$
$$\mathcal{L} \implies T_m(s) = \omega(s)(J s + f) \implies \omega(s) = \frac{T_m(s)}{J s + f} \quad \text{--- (3)}$$
4. Back EMF: $e_b(t) = K_b \omega(t) \implies E_b(s) = K_b \omega(s) \quad \text{--- (4)}$
5. Angular Position: $\omega = \frac{d\theta}{dt} \implies \Theta(s) = \frac{1}{s} \omega(s) \quad \text{--- (5)}$

$$\omega(s)(J s + f) = K_t \left[\frac{V_a(s) - K_b \omega(s)}{R_a + s L_a}\right]$$

Step 1: Operational Mechanism
A flyball governor regulates prime mover speed by throttling the fuel/steam supply. Centrifugal flyballs rotate with the engine shaft. When engine speed rises, centrifugal force moves the balls outward, lifting the sleeve upward. The linkage moves the pilot valve to port high-pressure hydraulic oil into the power cylinder, which drives the main fuel throttle valve downward, throttling fuel and restoring speed.
Step 2: Component Mathematical Modeling
1. Hydraulic Power Cylinder: Piston displacement $Y(s)$ is related to pilot valve displacement $X(s)$ by fluid flow:
$$A \rho \frac{dy}{dt} = K_1 x \implies A \rho s Y(s) = K_1 X(s) \implies Y(s) = \frac{K}{s} X(s) \quad \text{where } K = \frac{K_1}{A\rho}$$
2. Dashpot Linkage: Provides transient stabilizing reset: $Z(s) = \left[\frac{s T}{1 + s T}\right] Y(s)$
3. Differential Lever Kinematics: $X(s) = \left(\frac{b}{a+b}\right) E(s) - \left(\frac{a}{a+b}\right) Z(s)$
Step 3: Transfer Function Derivation
$$X(s) = \left(\frac{b}{a+b}\right) E(s) - \left(\frac{a}{a+b}\right)\left[\frac{s T}{1 + s T}\right] Y(s)$$
Substitute into $Y(s) = \frac{K}{s} X(s)$:
$$Y(s) = \frac{K}{s} \left[ \left(\frac{b}{a+b}\right) E(s) - \left(\frac{a}{a+b}\right)\left(\frac{s T}{1 + s T}\right) Y(s) \right]$$
$$Y(s)\left[1 + \frac{K}{s}\left(\frac{a}{a+b}\right)\left(\frac{s T}{1 + s T}\right)\right] = \frac{K}{s}\left(\frac{b}{a+b}\right) E(s)$$
$$\frac{Y(s)}{E(s)} = \frac{\frac{K}{s}\left(\frac{b}{a+b}\right)}{1 + \frac{K}{s}\left(\frac{a}{a+b}\right)\left[\frac{s T}{1 + s T}\right]}$$

Question: Describe the speed control of a prime mover (steam turbine). Draw its block diagram and derive its transfer function.
Step 1: System Description
In a steam turbine generating unit, the prime mover extracts thermal energy from high-pressure steam. Uncontrolled turbine acceleration can lead to runaway centrifugal rotor failure. A governor regulates a control valve throttling the steam mass flow rate to maintain constant synchronous speed (typically $3000\text{ rpm}$) despite load torque swings.
Step 2: Modeling Equations
1. Turbine Rotor Dynamics: Dynamic equilibrium of turbine rotor with inertia $J$ and damping $B$:
$$J \frac{d\omega(t)}{dt} + B \omega(t) = T(t)$$
$$\mathcal{L} \implies \omega(s)(J s + B) = T(s) \implies \omega(s) = \frac{T(s)}{J s + B} \quad \text{--- (1)}$$
2. Torque-Steam Flow Relation: Driving torque developed is proportional to valve control signal $u(t)$:
$$T(s) = K_t U(s) \quad \text{--- (2)}$$
Step 3: First-Order Transfer Function
Substituting (2) into (1):
$$\omega(s)(J s + B) = K_t U(s) \implies \frac{\Omega(s)}{U(s)} = \frac{K_t}{J s + B} = \frac{\frac{K_t}{B}}{\frac{J}{B} s + 1}$$
Defining steady-state gain $K = \frac{K_t}{B}$ and rotor time constant $\tau = \frac{J}{B}$:
$$\frac{\Omega(s)}{U(s)} = \frac{K}{\tau s + 1}$$
Q.4 Speed Control in Machine Tools (Summer-2026 Q.11, Winter-2025 Q.11 - 13 Marks)
Question: Explain the speed control of machine tools (CNC lathe/spindle) with a neat block diagram and derive the spindle speed transfer function.
Step 1: Need for Speed Control in Machine Tools
Modern machine tools (CNC turning centers, milling machines) require accurate spindle speed control to:
  • Maintain constant surface cutting speed ($V_c = \pi D N$) regardless of changing workpiece diameter.
  • Prevent premature cutting tool wear and chatter vibrations.
  • Ensure tight dimensional tolerances and superior surface finish.
Step 2: Modeling of Spindle Drive System
The drive comprises a power amplifier with gain $K_a$, armature-controlled DC spindle motor, and tachometer feedback.
Electrical: $V_a(s) = I_a(s)(R_a + s L_a) + K_b \omega(s)$
Mechanical: $T_m(s) = K_t I_a(s) = (J_t s + B_t)\omega(s)$, where $J_t = J_{\text{motor}} + J_{\text{spindle}}$ and $B_t = B_{\text{motor}} + B_{\text{cutting}}$.
Equating and solving for spindle speed $\Omega(s)$ versus amplifier input $V_a(s)$:
$$\frac{\Omega(s)}{V_a(s)} = \frac{K_t}{(J_t s + B_t)(R_a + s L_a) + K_t K_b}$$
