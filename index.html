Question: What is a closed loop control system? Explain with suitable examples. Distinguish between open loop and closed loop control systems, mentioning their advantages and disadvantages.
Definition: Closed Loop Control System
A closed loop control system is one in which the control action is dependent on the desired output via feedback. The output is continuously measured, fed back through a feedback element, and compared with the reference input at a summing junction to generate an actuating error signal that drives the controller to minimize deviation.
Examples: Automatic room air conditioner (temperature sensor feedback), home refrigerator, servomotor speed/position control, automobile cruise control.

Feedback provides high accuracy and noise rejection at the expense of circuit complexity and potential instability.
Q.2 Transfer Function: Definition, Significance & Properties (Winter-2024 Q.2b - 7 Marks)
Question: What is transfer function? State its significance and what must be the properties of a transfer function.
Definition
The transfer function of a linear time-invariant (LTI) system is defined as the ratio of the Laplace transform of the output variable to the Laplace transform of the input variable, assuming all initial conditions are zero.
$$G(s) = \frac{\mathcal{L}\{\text{Output } c(t)\}}{\mathcal{L}\{\text{Input } r(t)\}}\Bigg|_{\text{all initial conditions} = 0} = \frac{C(s)}{R(s)}$$
Significance
1. Algebraic System Modeling: Transforms high-order differential equations into algebraic equations in the complex frequency ($s$) plane.
2. Independent of Input: It is an inherent mathematical property of the plant network itself and does not depend on the applied input waveform.
3. Stability & Transient Extraction: Denominator roots (poles) indicate system stability and damping, while numerator roots (zeros) dictate transient peak responses.
4. Impulse Response Equivalence: The inverse Laplace transform of the transfer function gives the unit impulse response: $g(t) = \mathcal{L}^{-1}\{G(s)\}$.
Properties
1. Defined strictly for Linear Time-Invariant (LTI) systems.
2. Strictly requires zero initial energy storage (initial conditions = $0$).
3. For physically realizable physical systems, the degree of the denominator polynomial ($n$) is greater than or equal to that of the numerator ($m$).
4. It does not provide insight into the internal physical realization (an R-C circuit and a spring-damper system can have identical transfer functions).
Transfer function completely characterizes system dynamics in the s-domain independent of external excitation.

Q.4 Mason's Gain Formula: Signal Flow Graph (Summer-2026 Q.2a, Winter-2025 Q.2a, Summer-2025 Q.2b, Winter-2024 Q.2a - 7 Marks)
Question: Obtain the closed-loop transfer function $\frac{C(s)}{R(s)}$ of the system represented by the signal flow graph using Mason's gain formula. Forward path from $R(s)$ through $G_1-G_3-G_4-G_5-G_6$ to $C(s)$; Feedforward bypass branch $G_2$ from node after $G_1$ to node after $G_5$; Feedback loop $-H_1$ around $G_4$; Feedback loop $-H_2$ around $G_3-G_4-G_5$.
Step 1: Mason's Gain Formula Statement
$$T(s) = \frac{C(s)}{R(s)} = \frac{\sum_{k=1}^{N} P_k \Delta_k}{\Delta}$$
Where $P_k$ = gain of $k^{\text{th}}$ forward path, $\Delta = 1 - \sum L_i + \sum L_i L_j - \dots$, and $\Delta_k$ = path factor for $k^{\text{th}}$ forward path.
Step 2: Identify Forward Paths ($P_k$)
1. Path 1 (straight path through all cascaded blocks): $P_1 = G_1 G_3 G_4 G_5 G_6$
2. Path 2 (feedforward bypass through $G_2$): $P_2 = G_1 G_2 G_6$
Step 3: Identify Individual Feedback Loops ($L_i$)
1. Minor Loop 1 (around $G_4$): $L_1 = -G_4 H_1$
2. Major Loop 2 (around $G_3, G_4, G_5$): $L_2 = -G_3 G_4 G_5 H_2$
Step 4: Non-Touching Loops and Path Factors ($\Delta, \Delta_k$)
Both loops $L_1$ and $L_2$ share common nodes through $G_4$; therefore, there are no non-touching loop pairs ($\sum L_i L_j = 0$).
$$\Delta = 1 - (L_1 + L_2) = 1 - (-G_4 H_1 - G_3 G_4 G_5 H_2) = 1 + G_4 H_1 + G_3 G_4 G_5 H_2$$
Forward path $P_1$ touches both loops: $\Delta_1 = 1$. Forward path $P_2$ bypasses the loop nodes: $\Delta_2 = 1$ (if bypass nodes touch loop nodes, $\Delta_2 = 1$; if completely isolated from loop $L_1$, $\Delta_2 = 1 + G_4 H_1$). For standard exam graph: $\Delta_1 = 1, \Delta_2 = 1$.
Step 5: Overall Closed-Loop Transfer Function
$$T(s) = \frac{P_1 \Delta_1 + P_2 \Delta_2}{\Delta} = \frac{G_1 G_3 G_4 G_5 G_6 + G_1 G_2 G_6}{1 + G_4 H_1 + G_3 G_4 G_5 H_2}$$
$$\frac{C(s)}{R(s)} = \frac{G_1 G_6 (G_3 G_4 G_5 + G_2)}{1 + G_4 H_1 + G_3 G_4 G_5 H_2}$$
Q.5 Block Diagram Reduction Technique (Summer-2026 Q.1b, Winter-2025 Q.1b, Summer-2025 Q.1b, Winter-2024 Q.1b - 7 Marks)
Question: Using block diagram reduction technique, find the transfer function $\frac{C(s)}{R(s)}$ of the system with cascaded forward path $G_1, G_2$, feedback $H_1$ around $G_1$, and feedback $H_2$ from output $C(s)$ to the summing junction between $G_1$ and $G_2$.
Step 1: Eliminate the Inner Feedback Loop
The inner loop around block $G_2$ with feedback $H_2$ has an equivalent transfer function:
$$G_{2,\text{eq}} = \frac{G_2}{1 + G_2 H_2}$$
Step 2: Combine Cascaded Forward Blocks
Combining block $G_1$ in series with $G_{2,\text{eq}}$:
$$G_{\text{forward}} = G_1 \times G_{2,\text{eq}} = \frac{G_1 G_2}{1 + G_2 H_2}$$
Step 3: Eliminate Outer Feedback Loop with Feedback $H_1$
The outer closed loop contains $G_{\text{forward}}$ in the forward path and $H_1$ in the feedback path:
$$\frac{C(s)}{R(s)} = \frac{G_{\text{forward}}}{1 + G_{\text{forward}} H_1} = \frac{\frac{G_1 G_2}{1 + G_2 H_2}}{1 + \left(\frac{G_1 G_2}{1 + G_2 H_2}\right) H_1}$$
$$\frac{C(s)}{R(s)} = \frac{G_1 G_2}{1 + G_2 H_2 + G_1 G_2 H_1}$$
Q.6 Mechanical Translational Modeling & Analogies (Summer-2026 Q.2b, Winter-2025 Q.2b - 7 Marks)
Question: Write the differential equations governing the mechanical translational system shown below. Draw the electrical equivalent analogy circuits using Force-to-Voltage ($F-V$) and Force-to-Current ($F-I$) analogies. Masses $M_1$ and $M_2$, ground damper $B_1$, ground spring $K$, coupling damper $B_2$, applied external force $F(t)$ on $M_1$.
Step 1: Mechanical Differential Equations
Let $x_1(t)$ be the displacement of mass $M_1$, and $x_2(t)$ be the displacement of mass $M_2$.
For Mass $M_1$: Subjected to external force $F(t)$ and coupling damper $B_2$:
$$M_1 \frac{d^2 x_1}{dt^2} + B_2 \left(\frac{dx_1}{dt} - \frac{dx_2}{dt}\right) = F(t)$$
For Mass $M_2$: Connected to ground via damper $B_1$ and spring $K$, and coupled to $M_1$ via $B_2$:
$$M_2 \frac{d^2 x_2}{dt^2} + B_1 \frac{dx_2}{dt} + K x_2 + B_2 \left(\frac{dx_2}{dt} - \frac{dx_1}{dt}\right) = 0$$
Step 2: Force-Voltage ($F-V$) Analogy (Loop / Mesh Basis)
Mapping: Force $F \to e(t)$, Velocity $\dot{x} \to i(t)$, Mass $M \to L$, Damper $B \to R$, Spring $K \to \frac{1}{C}$.
$$\text{Mesh 1: } L_1 \frac{di_1}{dt} + R_2 (i_1 - i_2) = e(t)$$
$$\text{Mesh 2: } L_2 \frac{di_2}{dt} + R_1 i_2 + \frac{1}{C} \int i_2 dt + R_2 (i_2 - i_1) = 0$$
Step 3: Force-Current ($F-I$) Analogy (Nodal / Parallel Basis)
Mapping: Force $F \to i(t)$, Velocity $\dot{x} \to v(t)$, Mass $M \to C$, Damper $B \to \frac{1}{R}$, Spring $K \to \frac{1}{L}$.
$$\text{Node 1: } C_1 \frac{dv_1}{dt} + \frac{1}{R_2} (v_1 - v_2) = i(t)$$
$$\text{Node 2: } C_2 \frac{dv_2}{dt} + \frac{1}{R_1} v_2 + \frac{1}{L} \int v_2 dt + \frac{1}{R_2} (v_2 - v_1) = 0$$
Governing mechanical system mapped to 2-mesh loop circuit ($F-V$) and 2-node parallel circuit ($F-I$).

Q.1 Classification of Industrial Controllers & On-Off Action (Summer-2026 Q.3b, Winter-2025 Q.3b, Summer-2025 Q.3b - 7 Marks)
Question: What is basic control action? Classify industrial automatic controllers in detail. Describe briefly on-off controllers with a suitable example.
Classification of Control Actions
Basic control action refers to the fundamental method used by a controller to regulate a plant variable (temperature, pressure, speed, flow):
1. Discontinuous Control Action: Two-position or On-Off controller.
2. Continuous Control Actions:
  • Proportional ($P$) Action: $u(t) = K_p e(t)$
  • Integral ($I$) Action: $u(t) = K_i \int_0^t e(t) dt$
  • Derivative ($D$) Action: $u(t) = K_d \frac{de(t)}{dt}$
3. Composite Control Actions: Proportional-plus-Integral ($PI$), Proportional-plus-Derivative ($PD$), and Proportional-plus-Integral-plus-Derivative ($PID$).
On-Off (Two-Position) Controller
The controller output switches between two fixed states: fully ON ($100\%$) or fully OFF ($0\%$) depending on error sign:
$$u(t) = \begin{cases} U_{\max} & \text{when } e(t) > 0 \\ U_{\min} & \text{when } e(t) < 0 \end{cases}$$
Example: Bimetallic thermostat controlling an electric water heater. A small differential gap (dead-zone) prevents mechanical contact chattering.
On-off control creates sustained limit-cycle oscillations around the setpoint but provides high reliability and low cost.

Q.4 Hydraulic Proportional-Plus-Integral (PI) Controller (Winter-2025 Q.3a, Summer-2025 Q.3a - 7 Marks)
Question: Explain with neat sketch the working of a hydraulic proportional-plus-integral controller. Draw its block diagram and derive its transfer function.
Step 1: System Governing Equations
The controller uses a pilot spool valve, main power piston, differential feedback lever, and a dashpot arrangement.
1. Power cylinder flow equation: $A \rho s Y(s) = K_1 X(s) \implies Y(s) = \frac{K}{s} X(s)$, where $K = \frac{K_1}{A \rho}$.
2. Feedback linkage with dashpot: $Z(s) = \left[\frac{T s}{1 + T s}\right] Y(s)$
3. Input lever displacement: $X(s) = \left(\frac{b}{a+b}\right) E(s) - \left(\frac{a}{a+b}\right) Z(s) = \left(\frac{b}{a+b}\right) E(s) - \left(\frac{a}{a+b}\right)\left[\frac{T s}{1 + T s}\right] Y(s)$
Step 2: Derivation of Transfer Function
Substitute $X(s)$ into the power cylinder equation:
$$Y(s) = \frac{K}{s} \left[ \left(\frac{b}{a+b}\right) E(s) - \left(\frac{a}{a+b}\right)\left(\frac{T s}{1 + T s}\right) Y(s) \right]$$
$$Y(s) \left[ 1 + \left(\frac{a}{a+b}\right)\left(\frac{K}{s}\right)\left(\frac{T s}{1 + T s}\right) \right] = \left(\frac{b}{a+b}\right)\left(\frac{K}{s}\right) E(s)$$
Under normal operating conditions where loop gain $\frac{K}{s}\left(\frac{a}{a+b}\right)\left[\frac{Ts}{1+Ts}\right] \gg 1$:
$$\frac{Y(s)}{E(s)} \approx \frac{\left(\frac{b}{a+b}\right)\left(\frac{K}{s}\right)}{\left(\frac{a}{a+b}\right)\left(\frac{K}{s}\right)\left[\frac{T s}{1 + T s}\right]} = \left(\frac{b}{a}\right)\left[\frac{1 + T s}{T s}\right] = \left(\frac{b}{a}\right)\left[1 + \frac{1}{T s}\right]$$
$$\frac{Y(s)}{E(s)} = K_p \left(1 + \frac{1}{T_i s}\right) \quad \text{where } K_p = \frac{b}{a}, \ T_i = T$$

Step 1: Governing Equations
1. Pilot valve mass balance: $Y(s) = \frac{K}{s} X(s)$
2. Feedback displacement for PD action: $Z(s) = \left(\frac{1}{1 + sT}\right) Y(s)$
3. Input lever displacement: $X(s) = \left(\frac{b}{a+b}\right) E(s) - \left(\frac{a}{a+b}\right)\left(\frac{1}{1 + sT}\right) Y(s)$
Step 2: Algebraic Simplification

$$\frac{Y(s)}{E(s)} \approx \frac{\left(\frac{b}{a+b}\right)\left(\frac{K}{s}\right)}{\left(\frac{a}{a+b}\right)\left(\frac{K}{s}\right)\left(\frac{1}{1+sT}\right)} = \left(\frac{b}{a}\right) (1 + sT)$$

Q.6 Pneumatic Proportional & PID Controllers (Summer-2026 Q.4b, Summer-2025 Q.4b - 7 Marks)
Question: Sketch and explain the working of a pneumatic proportional controller and pneumatic PID controller. Derive the PID transfer function.
Pneumatic Proportional Controller Principle
A pneumatic proportional controller uses a flapper-nozzle mechanism with negative feedback bellows. Error displacement moves the flapper toward the nozzle, increasing nozzle back-pressure $P_c$. The pressure expands the feedback bellows, pulling the flapper back to establish equilibrium. Output pressure is proportional to error: $P_c(s) = K_p E(s)$.
Pneumatic PID Controller Transfer Function Derivation
In a pneumatic PID controller, an integral bellows (with needle valve resistance $R_i$) opposes the negative feedback bellows (with derivative resistance $R_d$).
The closed-loop transfer function of the pneumatic PID mechanism is:
$$\frac{P_c(s)}{E(s)} = \frac{\left(\frac{b}{a+b}\right) K}{1 + \left(\frac{a}{a+b}\right) K \left(\frac{A}{K_s}\right)\left[\frac{(T_i - T_d)s}{(1 + T_i s)(1 + T_d s)}\right]}$$
Under normal operation with loop gain $\gg 1$:
$$\frac{P_c(s)}{E(s)} \approx \left(\frac{b}{a}\right)\left(\frac{K_s}{A}\right)\left[\frac{(1 + T_i s)(1 + T_d s)}{(T_i - T_d)s}\right] \approx K_p \left[1 + T_d s + \frac{1}{T_i s}\right]$$
$$\frac{P_c(s)}{E(s)} = K_p \left(1 + T_d s + \frac{1}{T_i s}\right)$$
Q.7 Derivative Control Action Effects on System Performance (Winter-2024 Q.3b - 7 Marks)
Question: Explain derivative control action. Describe the effect of derivative control action on system performance.
Mathematical Definition
In derivative control, the controller output is directly proportional to the rate of change of the error signal:
$$u(t) = K_d \frac{de(t)}{dt} \implies U(s) = K_d s E(s)$$
Effects on Performance
1. Anticipatory Action: Responds to the slope of error, initiating corrective action before the error grows large.
2. Increases Damping: Adds an open-loop zero to the forward path, shifting closed-loop poles to the left and increasing $\zeta$.
3. Suppresses Oscillations: Significantly reduces maximum peak overshoot ($M_p$) and shortens settling time ($T_s$).
4. Susceptible to High-Frequency Noise: Derivative gain amplifies high-frequency noise ($\lim_{\omega \to \infty} |j\omega| = \infty$). It is never used alone; always combined with P (PD) or PI (PID).
Derivative action improves relative stability and speeds up transient decay, but does not eliminate steady-state error.

Transient Response: The initial part of the response that changes from initial value to final value before decaying to zero ($t \to \infty$).
Steady State Response: The fixed portion of output remaining after transient oscillations have vanished, measuring tracking accuracy.
Response Curve Sketch

Specification Formulas

Q.2 Standard Test Signals in Time Response Analysis (Winter-2024 Q.6b, Winter-2025 Q.6a - 6 Marks)
Question: Explain various types of standard test signals used in time response analysis with mathematical definitions and Laplace transforms.
Definitions & Mathematical Relations
1. Step Input (Displacement function): Sudden instantaneous change:
$$r(t) = A \quad (t \ge 0), \quad r(t) = 0 \quad (t < 0) \implies R(s) = \frac{A}{s} \quad (\text{Unit Step: } R(s) = \frac{1}{s})$$
2. Ramp Input (Velocity function): Linearly increasing signal:
$$r(t) = A t \quad (t \ge 0), \quad r(t) = 0 \quad (t < 0) \implies R(s) = \frac{A}{s^2} \quad (\text{Unit Ramp: } R(s) = \frac{1}{s^2})$$
3. Parabolic Input (Acceleration function): Accelerating signal:
$$r(t) = \frac{A}{2} t^2 \quad (t \ge 0), \quad r(t) = 0 \quad (t < 0) \implies R(s) = \frac{A}{s^3} \quad (\text{Unit Parabolic: } R(s) = \frac{1}{s^3})$$
4. Impulse Input (Shock function): Signal with infinite magnitude at $t = 0$ and unit area:
$$r(t) = \delta(t) \quad \text{where } \int_{-\infty}^\infty \delta(t) dt = 1 \implies R(s) = 1$$
Step tests position, ramp tests tracking velocity, parabolic tests acceleration, and impulse tests natural dynamics.

Definitions
1. Gain Crossover Frequency ($\omega_{gc}$): Frequency at which open-loop magnitude $|G(j\omega)H(j\omega)| = 1$ (or $0\text{ dB}$).

4. Phase Margin ($PM$): Additional phase lag allowed at gain crossover frequency: $PM = 180^\circ + \angle G(j\omega_{gc})H(j\omega_{gc})$.

Q.2 General Procedure for Construction of Bode Plot (Winter-2025 Q.9a - 5 Marks)
Question: State and explain the general procedure for construction of Bode plot.
Step-by-Step Procedure
1. Convert to Time-Constant Form: Express $G(s)H(s)$ in Bode form: $G(j\omega) = \frac{K(1 + j\omega T_a)\dots}{(j\omega)^N(1 + j\omega T_1)\dots}$.
2. Determine Corner Frequencies: Identify corner frequencies for each factor: $\omega_c = \frac{1}{T}$, and arrange in ascending order.
3. Determine Initial Slope: Governed by free integrators $(j\omega)^N$: Initial slope is $-20N\text{ dB/decade}$. Point at $\omega = 1\text{ rad/s}$ is $20\log_{10} K$.
4. Construct Magnitude Table: As frequency passes each corner frequency:
  • First-order pole $(1 + j\omega T)^{-1}$ adds $-20\text{ dB/decade}$.
  • First-order zero $(1 + j\omega T)$ adds $+20\text{ dB/decade}$.
  • Second-order complex pole adds $-40\text{ dB/decade}$.
5. Construct Phase Angle Table: Tabulate $\phi(\omega) = \sum \angle \text{Zeros} - \sum \angle \text{Poles} - N(90^\circ)$ over the frequency spectrum.
6. Extract Stability Margins: Read $\omega_{gc}$ (where magnitude $= 0\text{ dB}$) and $\omega_{pc}$ (where phase $= -180^\circ$). Compute $GM$ and $PM$.

Q.1 Armature-Controlled D.C. Servomotor (Winter-2025 Q.11, Summer-2025 Q.12, Winter-2024 Q.11, Summer-2026 Q.11 - 14 Marks)
Question: Explain the working of an armature-controlled D.C. servomotor. Draw its complete circuit diagram, block diagram, and derive its overall transfer function $\frac{\Theta(s)}{V_a(s)}$ and $\frac{\Omega(s)}{V_a(s)}$.
Step 1: Governing Physical Equations
In an armature-controlled DC motor, speed is controlled by varying armature voltage $V_a(t)$ while keeping field current $I_f$ constant.
1. Armature Circuit (KVL):
$$V_a(t) = R_a I_a(t) + L_a \frac{dI_a(t)}{dt} + e_b(t) \implies I_a(s) = \frac{V_a(s) - E_b(s)}{R_a + s L_a} \quad \text{--- (1)}$$
2. Torque Equation: With constant field flux $\phi \implies T_m(t) = K_t I_a(t) \implies T_m(s) = K_t I_a(s) \quad \text{--- (2)}$
3. Mechanical Load Dynamics:
$$T_m(t) = J \frac{d^2\theta}{dt^2} + f \frac{d\theta}{dt} = J \frac{d\omega}{dt} + f \omega \implies \omega(s) = \frac{T_m(s)}{J s + f} \quad \text{--- (3)}$$
4. Back EMF Equation: $e_b(t) = K_b \omega(t) \implies E_b(s) = K_b \omega(s) \quad \text{--- (4)}$
5. Angular Position Relation: $\omega = \frac{d\theta}{dt} \implies \Theta(s) = \frac{1}{s} \omega(s) \quad \text{--- (5)}$
Step 2: Closed-Loop Block Diagram
Va(s) + 1 Ia(s) Tm(s) 1 w(s) 1 theta(s) ----->(+)-->[-------]-------->[ Kt ]------->[------]----->[ - ]---> ^ - [Ra+sLa ] [Js + f] [ s ] | | |-----------------[ Kb ]<---------------|
Step 3: Transfer Function Derivation
Substitute $I_a(s)$ from (1) into (2), and equate to (3):
$$\omega(s)(J s + f) = K_t \left[\frac{V_a(s) - K_b \omega(s)}{R_a + s L_a}\right]$$
$$\omega(s)\left[(J s + f)(R_a + s L_a) + K_t K_b\right] = K_t V_a(s)$$
$$\frac{\Omega(s)}{V_a(s)} = \frac{K_t}{(R_a + s L_a)(J s + f) + K_t K_b}$$
Since position $\Theta(s) = \frac{\Omega(s)}{s}$:
$$\frac{\Theta(s)}{V_a(s)} = \frac{K_t}{s \left[(R_a + s L_a)(J s + f) + K_t K_b\right]}$$

A flyball governor regulates prime mover speed by controlling the fuel valve. Flyballs rotate with the engine shaft. Step 2: Mathematical Modeling & Derivation
1. Hydraulic Power Cylinder: Piston displacement $Y(s)$ is related to spool valve displacement $X(s)$ by fluid flow:
$$A \rho s Y(s) = K_1 X(s) \implies Y(s) = \frac{K}{s} X(s) \quad \text{where } K = \frac{K_1}{A \rho}$$
2. Dashpot Feedback Linkage: Provides transient reset stabilizing action: $Z(s) = \left[\frac{s T}{1 + s T}\right] Y(s)$
3. Differential Lever Kinematics: $X(s) = \left(\frac{b}{a+b}\right) E(s) - \left(\frac{a}{a+b}\right) Z(s) = \left(\frac{b}{a+b}\right) E(s) - \left(\frac{a}{a+b}\right)\left[\frac{s T}{1 + s T}\right] Y(s)$

$$Y(s) = \frac{K}{s} \left[ \left(\frac{b}{a+b}\right) E(s) - \left(\frac{a}{a+b}\right)\left(\frac{s T}{1 + s T}\right) Y(s) \right]$$
$$\frac{Y(s)}{E(s)} = \frac{\frac{K}{s}\left(\frac{b}{a+b}\right)}{1 + \frac{K}{s}\left(\frac{a}{a+b}\right)\left[\frac{s T}{1 + s T}\right]}$$
Q.4 Speed Control of Prime Mover (Steam Turbine) (Summer-2026 Q.12, Winter-2024 Q.12 - 13 Marks)
Question: Describe the speed control of a prime mover (steam turbine). Draw its block diagram and derive its transfer function.
Step 1: System Description
In a steam turbine generating unit, the governor acts on a throttle valve to regulate the mass flow rate of steam to the blades. Rapid load variations cause speed fluctuations. The governor restores the shaft speed to synchronous speed (typically $3000\text{ rpm}$) to prevent overspeed tripping and rotor damage.
Step 2: Mathematical Derivation
1. Turbine Rotor Dynamics: Dynamic balance of turbine rotor having inertia $J$ and viscous friction damping $B$:
$$T(t) = J \frac{d\omega(t)}{dt} + B \omega(t) \implies T(s) = \omega(s)(J s + B) \quad \text{--- (1)}$$
2. Torque-Steam Flow Relation: Driving torque developed is proportional to valve control signal $u(t)$:
$$T(s) = K_t U(s) \quad \text{--- (2)}$$
Equating (1) and (2):
$$\omega(s)(J s + B) = K_t U(s) \implies \frac{\Omega(s)}{U(s)} = \frac{K_t}{J s + B} = \frac{\frac{K_t}{B}}{\frac{J}{B} s + 1}$$
$$\frac{\Omega(s)}{U(s)} = \frac{K}{\tau s + 1} \quad \text{where steady-state gain } K = \frac{K_t}{B}, \ \tau = \frac{J}{B}$$
