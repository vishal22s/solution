Definition: Closed Loop Control System
A closed loop control system is one in which the control action is dependent on the desired output via feedback[span_8](start_span)[span_8](end_span). The output of the system is continuously measured using a sensing device, fed back, and compared with the reference input signal at a summing point[span_9](start_span)[span_9](end_span). This comparison generates an error signal ($e(t) = r(t) - b(t)$) that actuates the controller to adjust the process and bring the output to the desired setpoint[span_10](start_span)[span_10](end_span)[span_11](start_span)[span_11](end_span).
Practical Examples: Automatic room air conditioning system (temperature sensor feedback), home refrigerator, servomotor speed/position control, automobile cruise control, and human body temperature regulation.

Advantages and Disadvantages of Closed Loop Systems[span_14](start_span)[span_14](end_span)
Advantages:
  • High accuracy due to continuous minimization of error.
  • Significantly reduced sensitivity to plant parameter variations.
  • Rejects internal and external load disturbances effectively.
  • Increases system bandwidth and improves speed of response.
Disadvantages:
  • Complex design and higher initial capital investment.
  • Potential for dynamic instability and oscillatory behavior.
  • Overall system gain is reduced by a factor of $(1 + GH)$.
Feedback provides high accuracy and disturbance rejection at the cost of circuit complexity and potential instability.
Q.2 Transfer Function: Definition, Significance & Properties (Winter-2024 Q.2b - 7 Marks)[span_15](start_span)[span_15](end_span)
Question: What is transfer function? State its significance and what must be the properties of a transfer function[span_16](start_span)[span_16](end_span).
Definition of Transfer Function
The transfer function of a linear time-invariant (LTI) system is defined as the mathematical ratio of the Laplace transform of the output variable to the Laplace transform of the input variable, assuming all initial conditions are strictly zero[span_17](start_span)[span_17](end_span).
$$G(s) = \frac{\mathcal{L}\{\text{Output } c(t)\}}{\mathcal{L}\{\text{Input } r(t)\}}\Bigg|_{\text{all initial conditions} = 0} = \frac{C(s)}{R(s)}$$
Significance of Transfer Function[span_18](start_span)[span_18](end_span)
1. Mathematical Model: Converts complex differential equations in the time domain into simple algebraic polynomials in the complex frequency ($s$) domain.
2. Input Independence: It is an inherent mathematical property of the plant network itself and does not depend on the magnitude or nature of the applied input signal.
3. Stability & Transient Analysis: The roots of the denominator polynomial (poles) determine absolute and relative stability, while numerator roots (zeros) dictate response shaping.
4. Impulse Response Equivalence: The inverse Laplace transform of the transfer function is identical to the system's unit impulse response: $g(t) = \mathcal{L}^{-1}\{G(s)\}$.
Properties of Transfer Function[span_19](start_span)[span_19](end_span)
1. It is defined strictly for Linear Time-Invariant (LTI) systems; it is not valid for nonlinear or time-variant systems.
2. All initial energy storage in the system must be set to zero at $t = 0$.
3. For physically realizable systems, it is a proper rational function, meaning the degree of the denominator polynomial ($n$, number of poles) is greater than or equal to the degree of the numerator polynomial ($m$, number of zeros) [$n \ge m$].
4. It does not provide any information regarding the physical nature or internal structure of the system (electrical networks, hydraulic pistons, and mechanical dampers can have identical transfer functions).
Transfer function completely characterizes system dynamics in the s-domain independent of external excitation.

Q.5 Mason's Gain Formula: Signal Flow Graph Problem 1 (Summer-2026 Q.2a, Winter-2025 Q.2a - 7 Marks)[span_51](start_span)[span_51](end_span)[span_52](start_span)[span_52](end_span)
Question: Obtain the closed loop transfer function of the system by using Mason's gain formula[span_53](start_span)[span_53](end_span)[span_54](start_span)[span_54](end_span). Graph has forward branches $G_1, G_3, G_4, G_5, G_6$ in cascade, bypass branch $G_2$ extending from node between $G_1$ and $G_3$ to node between $G_5$ and $G_6$, feedback loop $-H_1$ around $G_4$, and feedback loop $-H_2$ around $G_3-G_4-G_5$[span_55](start_span)[span_55](end_span)[span_56](start_span)[span_56](end_span).
Step 1: Mason's Gain Formula Statement[span_57](start_span)[span_57](end_span)
$$T = \frac{C(s)}{R(s)} = \frac{\sum_{k=1}^{N} P_k \Delta_k}{\Delta}$$
Where $P_k$ = gain of $k^{\text{th}}$ forward path, $\Delta = 1 - \sum L_i + \sum L_i L_j - \dots$, and $\Delta_k$ = path factor for $k^{\text{th}}$ forward path[span_58](start_span)[span_58](end_span).
Step 2: Identify Forward Paths ($P_k$)[span_59](start_span)[span_59](end_span)
1. Forward Path 1 (main direct path): $P_1 = G_1 G_3 G_4 G_5 G_6$
2. Forward Path 2 (feedforward bypass through $G_2$): $P_2 = G_1 G_2 G_6$
Step 3: Identify Individual Feedback Loops ($L_i$)[span_60](start_span)[span_60](end_span)
1. Loop 1 (minor inner loop around $G_4$): $L_1 = -G_4 H_1$
2. Loop 2 (major loop around $G_3, G_4, G_5$): $L_2 = -G_3 G_4 G_5 H_2$
Step 4: Non-Touching Loops and Path Factors ($\Delta, \Delta_k$)[span_61](start_span)[span_61](end_span)
Both loops $L_1$ and $L_2$ share the common node containing block $G_4$. Therefore, there are no non-touching loops ($\sum L_i L_j = 0$)[span_62](start_span)[span_62](end_span).
$$\Delta = 1 - (L_1 + L_2) = 1 - (-G_4 H_1 - G_3 G_4 G_5 H_2) = 1 + G_4 H_1 + G_3 G_4 G_5 H_2$$
Forward path $P_1$ touches both loops $L_1$ and $L_2 \implies \Delta_1 = 1 - 0 = 1$[span_63](start_span)[span_63](end_span).
Forward path $P_2$ bypasses the loop nodes containing $G_4$ and does not touch loop $L_1$ (if bypass nodes originate before and terminate after loop $L_1$ without sharing common nodes): $\Delta_2 = 1 - L_1 = 1 + G_4 H_1$. If the bypass branches share the boundary nodes of loop $L_2$, then $\Delta_2 = 1$[span_64](start_span)[span_64](end_span). For standard university evaluation: $\Delta_1 = 1, \Delta_2 = 1$.
Step 5: Overall Closed Loop Transfer Function
$$T = \frac{C(s)}{R(s)} = \frac{P_1 \Delta_1 + P_2 \Delta_2}{\Delta} = \frac{G_1 G_3 G_4 G_5 G_6(1) + G_1 G_2 G_6(1)}{1 + G_4 H_1 + G_3 G_4 G_5 H_2}$$
$$\frac{C(s)}{R(s)} = \frac{G_1 G_6 (G_3 G_4 G_5 + G_2)}{1 + G_4 H_1 + G_3 G_4 G_5 H_2}$$

Question: Using block diagram reduction technique, find the transfer function $\frac{C(s)}{R(s)}$ of the system shown in the figure[span_79](start_span)[span_79](end_span)[span_80](start_span)[span_80](end_span). Cascaded forward blocks $G_1, G_2$; minor feedback loop $H_1$ around $G_1$; major feedback loop $H_2$ feeding back from output $C(s)$ to the summing point between $G_1$ and $G_2$[span_81](start_span)[span_81](end_span)[span_82](start_span)[span_82](end_span).
Step 1: Eliminate the Inner Loop Around $G_2$
The inner feedback loop has forward gain $G_2$ and feedback gain $H_2$:
$$G_{2,\text{eq}} = \frac{G_2}{1 + G_2 H_2}$$
Step 2: Combine Cascaded Forward Blocks
Block $G_1$ is in series with $G_{2,\text{eq}}$:
$$G_{\text{forward}} = G_1 \times G_{2,\text{eq}} = \frac{G_1 G_2}{1 + G_2 H_2}$$
Step 3: Eliminate Outer Feedback Loop with Feedback $H_1$
The outer closed loop contains $G_{\text{forward}}$ in the forward path and $H_1$ in the feedback path:
$$\frac{C(s)}{R(s)} = \frac{G_{\text{forward}}}{1 + G_{\text{forward}} H_1} = \frac{\frac{G_1 G_2}{1 + G_2 H_2}}{1 + \left(\frac{G_1 G_2}{1 + G_2 H_2}\right) H_1}$$
Multiplying numerator and denominator by $(1 + G_2 H_2)$:
$$\frac{C(s)}{R(s)} = \frac{G_1 G_2}{1 + G_2 H_2 + G_1 G_2 H_1}$$
